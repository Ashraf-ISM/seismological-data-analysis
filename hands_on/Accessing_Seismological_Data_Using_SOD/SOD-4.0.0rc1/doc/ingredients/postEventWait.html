postEventWait

When running SOD in realtime mode, this tells it how long to wait after a fresh event before trying to get data. This allows for data that isn't immediately available to be submitted to the seismogram servers. For more information look at the Realtime Run Considerations for more details on how to use this subsetter in conjunction with the other availableData subsetters.

Example 

<postEventWait>
  <unit>HOUR</unit>
  <value>42.189</value>
</postEventWait>

This consists of

<postEventWait>

timeInterval interleave
<unit>
<value>float</value>
</postEventWait>
