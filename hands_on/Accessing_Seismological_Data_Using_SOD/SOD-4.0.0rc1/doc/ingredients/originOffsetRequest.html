originOffsetRequest

This generates requests for a certain window around the time the event occured.

Example 

<originOffsetRequest>
    <beginOffset>
        <unit>MINUTE</unit>
        <value>-20</value>
    </beginOffset>
    <endOffset>
        <unit>HOUR</unit>
        <value>1</value>
    </endOffset>
</originOffsetRequest>

This consists of

<originOffsetRequest>

<beginOffset>
timeInterval
</beginOffset>
<endOffset>
timeInterval
</endOffset>
</originOffsetRequest>

Places this can be found

In requestGenerator there is a choice between all of the following

  • phaseRequest
  • originOffsetRequest
  • choiceRequest
  • combineRequest
  • requestGeneratorScript
