seismogramImageProcess

Make images of the processed seismograms

Example 

<seismogramImageProcess/>

This consists of

<seismogramImageProcess>

seismogramImageBase
<displayConfig> optional
basicSeismogramDisplayContents
</displayConfig>
</seismogramImageProcess>
