range

A range of lengths

Example 

<unit>KILOMETER</unit>
<min>0</min>
<max>36</max>

This consists of

<unit>
<min>double</min> optional
<max>double</max> optional

backAzimuthRange contains this directly

stationDepthRange contains this directly

distanceRange contains this directly

  • latitude
  • longitude
  • range
