stationPointDistance

True if the station is within the given distance range of the given lat and lon.

Example 

<stationPointDistance>
  <latitude>35</latitude>
  <longitude>-80</longitude>
  <unit>KILOMETER</unit>
  <min>0</min>
  <max>36</max>
</stationPointDistance>

This consists of

<stationPointDistance>

latLonUnitRange interleave
<latitude>
<longitude>
range
</stationPointDistance>
