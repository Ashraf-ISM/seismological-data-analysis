requestGenerator

Ingredients that generating requests to the seismogram servers

Example 

<phaseRequest>
  <beginPhase>ttp</beginPhase>
  <beginOffset>
      <unit>SECOND</unit>
      <value>-60</value>
  </beginOffset>
  <endPhase>ttp</endPhase>
  <endOffset>
      <unit>SECOND</unit>
      <value>360</value>
  </endOffset>
</phaseRequest>

This consists of

requestGenerator choice

<choiceRequest>
<combineRequest>
<originOffsetRequest>
<phaseRequest>
<requestGeneratorScript>
