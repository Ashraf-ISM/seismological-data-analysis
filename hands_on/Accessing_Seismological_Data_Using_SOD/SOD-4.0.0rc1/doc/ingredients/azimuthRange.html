azimuthRange

This accepts event station pairs where the azimuth from the preferred origin to the station is within the range given in degrees.

Example 

<azimuthRange>
    <unit>DEGREE</unit>
    <min>30</min>
    <max>90</max>
</azimuthRange>

This consists of

<azimuthRange>

<unit>
<min>double</min> optional
<max>double</max> optional
</azimuthRange>

Places this can be found

In eventStation there is a choice between all of the following

  • distanceRange
  • printlineEventStation
  • azimuthRange
  • backAzimuthRange
  • linearDistanceMagnitudeRange
  • eventStationAND
  • eventStationOR
  • eventStationNOT
  • midPoint
  • removeStationDuplicate
  • phaseExists
  • phaseWithoutInterference
  • eventStationScript
  • externalEventStationSubsetter
