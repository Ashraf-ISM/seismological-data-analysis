ANDAvailableDataWrapper

Allows an event channel available data subsetter to be embedded within an event channelgroup available data subsetter. The result is the AND of result of all the individual per channel available data subsetters. The is most often used within the motion vector arm.

Example 

<ANDAvailableDataWrapper>
    <noGaps />
</ANDAvailableDataWrapper>

This consists of

<ANDAvailableDataWrapper>

availableData choice
<availableDataAND>
<availableDataNOT>
<availableDataOR>
<availableDataScript>
<externalAvailableDataSubsetter>
<fullCoverage/>
<noGaps/>
<percentCoverage>
<postEventWait>
<printlineAvailableDataProcess>
<someCoverage/>
<subrequestCoverage>

</ANDAvailableDataWrapper>

Places this can be found

In vectorAvailableData there is a choice between all of the following

  • ANDAvailableDataWrapper
  • ORAvailableDataWrapper
  • vectorAvailableDataAND
  • vectorAvailableDataOR
  • vectorAvailableDataNOT
  • vectorAvailableDataScript
  • externalVectorAvailableDataSubsetter
  • availableData
