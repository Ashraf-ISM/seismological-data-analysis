eventArm

The event arm gathers events from one or more event sources. The event arm then processes each event through any origin subsetters present. After this point, the events are marked as accepted and the waveform arm begins to work on them.

Example 

<eventArm>
    <fdsnEvent>
        <originTimeRange>
            <startTime>
                2015-01-01T00:00:00.000Z
            </startTime>
            <endTime>
                2015-01-31T23:59:59.999Z
            </endTime>
        </originTimeRange>
        <magnitudeRange>
            <min>6.0</min>
        </magnitudeRange>
    </fdsnEvent>
    <removeEventDuplicate />
    <printlineEventProcess />
</eventArm>
