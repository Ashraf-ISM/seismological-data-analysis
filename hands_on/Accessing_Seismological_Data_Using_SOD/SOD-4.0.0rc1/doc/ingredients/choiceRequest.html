choiceRequest

This generates requests for the first embedded request generator whose Event-Channel subsetter matches. This allows different time windows based on magnitude or distance from the station.

Example 

<choiceRequest>
  <choice>
    <bestChannelAtStation/>
    <phaseRequest>
      <beginPhase>ttp</beginPhase>
      <beginOffset>
          <unit>SECOND</unit>
          <value>-60</value>
      </beginOffset>
      <endPhase>ttp</endPhase>
      <endOffset>
          <unit>SECOND</unit>
          <value>360</value>
      </endOffset>
    </phaseRequest>
  </choice>
</choiceRequest>

This consists of

<choiceRequest>

<choice> At least once
eventChannelPlus
requestGenerator
</choice>
<otherwise> optional
requestGenerator
</otherwise>
</choiceRequest>

Places this can be found

In requestGenerator there is a choice between all of the following

  • phaseRequest
  • originOffsetRequest
  • choiceRequest
  • combineRequest
  • requestGeneratorScript
