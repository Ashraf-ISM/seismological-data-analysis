plottableRequest

Retrieves plottables for the given request.

Example 

<plottableRequest>
  <name>text</name>
  <dns>text</dns>
  <pixelsPerDay>text</pixelsPerDay>
</plottableRequest>

This consists of

<plottableRequest>

<name>Any text</name>
<dns>Any text</dns>
<pixelsPerDay>Token</pixelsPerDay> At least once
</plottableRequest>

Places this can be found

In request there is a choice between all of the following

  • requestAND
  • requestOR
  • requestNOT
