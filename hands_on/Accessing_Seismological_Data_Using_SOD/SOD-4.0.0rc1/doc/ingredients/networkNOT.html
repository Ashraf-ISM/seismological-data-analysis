networkNOT

The output is the logical NOT of the output of the enclosed Network subsetter. This means that it will evaluate to false if the enclosed Network subsetter evaluates to true, and vice versa.

Example 

<networkNOT>
  <networkCode>IC</networkCode>
</networkNOT>

This consists of

network choice

<externalNetworkSubsetter>
<networkAND>
<networkEffectiveTimeOverlap>
<networkName>

</networkNOT>
