printlineAvailableDataProcess

This prints information regarding the availability of seismic data configured with template to the file in filename, or to standard out if filename is left out. Filename and template are Velocity templates. Both templates contain a list of request named originalRequests that are the requests generated by your request generator, another list of request named availableRequests that are the requests the server said were available for retrieval, site, station and net variables. Template defaults to "Got $availableRequests.size()".

Example 

<printlineAvailableDataProcess/>

This consists of

<printlineAvailableDataProcess>

interleave
<template>Any Text</template> optional
<filename>Any Text</filename> optional
</printlineAvailableDataProcess>

Places this can be found

In availableData there is a choice between all of the following

  • fullCoverage
  • postEventWait
  • noGaps
  • someCoverage
  • subrequestCoverage
  • percentCoverage
  • availableDataAND
  • availableDataOR
  • availableDataNOT
  • availableDataScript
