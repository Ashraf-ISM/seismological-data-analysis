percentCoverage

Accepts data if it spans the specified percentage of the generated request

Example 

<percentCoverage>12.57</percentCoverage>

This consists of

<percentCoverage>double</percentCoverage>

Places this can be found

In availableData there is a choice between all of the following

  • fullCoverage
  • postEventWait
  • noGaps
  • someCoverage
  • subrequestCoverage
