loserEventCleaner

If present, SOD removes failed events from the database once a week. This will greatly speed things up if a run goes for years and gathers tens of thousands of rejected events. Defaults to FALSE.

Example 

<loserEventCleaner>TRUE</loserEventCleaner>

This consists of

<loserEventCleaner>

trueOrFalse choice
TRUE
FALSE

</loserEventCleaner>
