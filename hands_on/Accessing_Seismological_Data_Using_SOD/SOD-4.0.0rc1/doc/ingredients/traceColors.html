traceColors

A list of colors to use for seismograms added to the display. The first trace gets the first color, the second trace gets the second color and so on and so forth.

Example 

<traceColors>
  <color/>
</traceColors>

This consists of

<traceColors>

defineAndReference
<color> At least once
</traceColors>
