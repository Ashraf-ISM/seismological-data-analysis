externalNetworkSubsetter

Makes decisions and works on a seismic network. That includes the time the network was active, its name, operator, code and description

The jython class defined in class must implement NetworkSubsetter like this example implementation.

For more information on externals, see the externals documentation

Example 

<externalNetworkSubsetter>
    <classname>edu.somewhere.seis.sodExt.subsetter.network.MyNetworkSubsetter</classname>
</externalNetworkSubsetter>

This consists of

<externalNetworkSubsetter>

<classname>Any text</classname>
</externalNetworkSubsetter>
