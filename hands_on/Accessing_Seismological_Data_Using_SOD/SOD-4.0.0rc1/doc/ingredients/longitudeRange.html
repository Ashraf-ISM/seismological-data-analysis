longitudeRange

From min to max longitude measured in degrees from the Grenwich meridian, positive is east

Example 

<longitudeRange>
  <min>-80</min>
  <max>-80</max>
</longitudeRange>

This consists of

<longitudeRange>

<min>longitudeData</min> optional
<max>longitudeData</max> optional
</longitudeRange>

Places this can be found

eventBoxArea contains this directly

siteBoxArea contains this directly

stationBoxArea contains this directly
