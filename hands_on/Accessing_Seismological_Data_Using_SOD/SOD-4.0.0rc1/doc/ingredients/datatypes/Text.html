Any Text

Any amount of text can go here. You must escape the characters XML uses like < with &lt; so that it SOD doesn't think you're adding more tags, but other than that, anything goes.

Escaped Character Escape Sequence
" &quot;
' &apos;
< &lt;
> &gt;
