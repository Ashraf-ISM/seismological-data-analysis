Float

A number that can have a decimal portion that is stored in 32 bits. It also accepts exponential notation.

Valid Values

  • 123.456
  • +1234.456
  • -1.2344e56
  • -.45E-6

Invalid Values

  • 123.4E 56 - No spaces in the value
  • 123.6E+2.5 - Power of 10 must be an integer
