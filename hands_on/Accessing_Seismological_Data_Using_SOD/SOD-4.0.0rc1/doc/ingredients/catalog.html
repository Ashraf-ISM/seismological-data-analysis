catalog

Checks the catalog to which an event belongs against the string specified here. If they match, the event passes. The current list of known catalogs for the IRIS FDSN Event web service can be found here.

Example 

<catalog>NEIC PDE</catalog>

This consists of

<catalog>Any text</catalog>
