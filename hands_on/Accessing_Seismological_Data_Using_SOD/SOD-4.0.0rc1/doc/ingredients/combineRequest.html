combineRequest

This combines the requests generated by the embedded request generators. This allows multiple time windows to be processed at once.

Example 

<combineRequest>
  <phaseRequest>
    <beginPhase>ttp</beginPhase>
    <beginOffset>
        <unit>SECOND</unit>
        <value>-60</value>
    </beginOffset>
    <endPhase>ttp</endPhase>
    <endOffset>
        <unit>SECOND</unit>
        <value>360</value>
    </endOffset>
  </phaseRequest>
</combineRequest>

This consists of

<combineRequest>

requestGenerator At least once choice
<choiceRequest>
<combineRequest>
<originOffsetRequest>
<phaseRequest>
<requestGeneratorScript>

</combineRequest>
