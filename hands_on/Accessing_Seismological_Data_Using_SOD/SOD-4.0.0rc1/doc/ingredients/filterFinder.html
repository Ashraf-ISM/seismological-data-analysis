filterNetworkFinder

Finds networks and only allows in stations matching reg exps loaded from a url

Example 

<networkFinder>
    <name>IRIS_NetworkDC</name>
    <dns>edu/iris/dmc</dns>
    <refreshInterval>
        <unit>MINUTE</unit>
        <value>3000</value>
    </refreshInterval>
    <filterURL>http://seis.sc.edu/GEE/Dynamic/GEE_2.1/configs/filterStations.txt</filterURL>
</networkFinder>

This consists of

<filterNetworkFinder>

<name>
<dns>
<refreshInterval> optional
<filterURL>Any text</filterURL>
</filterNetworkFinder>

Places this can be found

In networkSource there is a choice between all of the following

  • fdsnStation
  • networkFinder
  • filterNetworkFinder
  • channelLimitedNetworkFinder
  • CSVNetworkSource
  • winstonNetworkSource
  • combineNetworkSource
  • stationXML
