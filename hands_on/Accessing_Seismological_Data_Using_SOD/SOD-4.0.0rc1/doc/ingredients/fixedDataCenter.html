fixedDataCenter

DHI servers at the IRIS DMC will be turned off June 2013. The fdsnDataSelect web service is the replacement. This specifies the data center to use.

Example 

<fixedDataCenter>
  <name>IRIS_DataCenter</name>
  <dns>edu/iris/dmc</dns>
</fixedDataCenter>

This consists of

<fixedDataCenter>

<name>
<dns>
<retries>integer</retries> optional
</fixedDataCenter>

Places this can be found

In seismogramSource there is a choice between all of the following

  • fdsnDataSelect
  • choiceSource
  • tryInOrder
  • winstonWaveServer
  • fixedDataCenter
