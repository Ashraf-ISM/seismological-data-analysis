OREventChannelWrapper

Allows an event channel subsetter to be embedded within a event channelgroup subsetter. The result is the OR of result of all the individual channels. The is most often used within the motion vector arm.

Example 

<OREventChannelWrapper>
        <bandCode>B</bandCode>
</OREventChannelWrapper>

This consists of

<OREventChannelWrapper>

eventChannelPlus choice
channelPlus
eventChannel
eventStation
origin

</OREventChannelWrapper>

Places this can be found

In eventVector there is a choice between all of the following

  • bestChannelAtStation
  • ANDEventChannelWrapper
  • OREventChannelWrapper
  • eventVectorAND
  • eventVectorOR
  • eventVectorNOT
  • eventVectorScript
  • externalEventVectorSubsetter
  • eventChannel
