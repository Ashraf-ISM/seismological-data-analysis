siteDepthRange

Matches sites at a range of depths below the surface. This might be used to separate surface sites from borehole sites.

Example 

<siteDepthRange>
    <unit>METER</unit>
    <min>100</min>
    <max>200</max>
</siteDepthRange>

This consists of

<siteDepthRange>

<unit>
<min>double</min> optional
<max>double</max> optional
</siteDepthRange>
