subrequestCoverage

This subsetter generates a new request with the specified request generator. If an availableData subsetter is defined in this element, it is used to check the generated request. If none is specified fullCoverage is used.

Example 

<subrequestCoverage>
  <phaseRequest>
    <beginPhase>ttp</beginPhase>
    <beginOffset>
        <unit>SECOND</unit>
        <value>-60</value>
    </beginOffset>
    <endPhase>ttp</endPhase>
    <endOffset>
        <unit>SECOND</unit>
        <value>360</value>
    </endOffset>
  </phaseRequest>
</subrequestCoverage>

This consists of

<subrequestCoverage>

requestGenerator
availableData optional
</subrequestCoverage>

Places this can be found

In availableData there is a choice between all of the following

  • fullCoverage
  • postEventWait
  • noGaps
  • someCoverage
  • subrequestCoverage
  • percentCoverage
  • availableDataAND
  • availableDataOR
  • availableDataNOT
  • availableDataScript
  • externalAvailableDataSubsetter
  • printlineAvailableDataProcess
