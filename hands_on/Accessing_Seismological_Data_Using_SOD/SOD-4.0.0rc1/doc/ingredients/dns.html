dns

The server's dns is used in combination with a name value to find an event DC. The name "IRIS_EventDC" must be used in combination with the "edu/iris/dmc" dns value. The names "NCEDC_EventDC" and "NCSN_EventDC" must be used in conjunction with the "edu/berkley/geo/quake" dns value. The name "SCEPPEventDC" must be used in conjunction with a DNS value "edu/sc/seis"

Example 

<dns>edu/iris/dmc</dns>
