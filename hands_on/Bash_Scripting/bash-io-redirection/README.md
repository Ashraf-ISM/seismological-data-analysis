# Bash Input/Output Redirection

This repository demonstrates fundamental Bash concepts:

- stdin (0)
- stdout (1)
- stderr (2)
- Here Documents
- Combined Redirection
- /dev/null usage

## Concepts Covered

| Descriptor | Number | Purpose |
|------------|--------|----------|
| stdin      | 0      | Input |
| stdout     | 1      | Normal output |
| stderr     | 2      | Error messages |
