# Seismological Data Analysis

This repository contains **hands-on codes, workflows, and assignments** for the course  
**NGPD510 – Seismological Data Analysis**.

All analysis is performed primarily using the **Ubuntu Linux terminal**, following
reproducible and research-oriented workflows commonly used in seismology and geophysics.

---

## 🎯 Objectives

- Perform seismic data analysis using **command-line tools**
- Understand waveform processing from raw seismic records
- Apply filtering, spectral analysis, and signal processing techniques
- Build reproducible workflows suitable for research and publications
- Maintain clean version control using **Git & GitHub**

---

## 🛠 Tools & Technologies

- **Linux (Ubuntu) Terminal**
- **SAC (Seismic Analysis Code)**
- **Python** (ObsPy, NumPy, SciPy, Matplotlib)
- **Bash / Shell scripting**
- **GMT** (where applicable)
- **Git & GitHub**
